# p132 全局优化与特征路线讨论

正式讨论稿见 `/output/p132_全局优化与特征路线_2026-11-20.md`。

核心边界：

- 先固定标准 PatchTST 的 p132 基线：三输入特征、MSE、direct 132。
- 标准基线只搜索模型容量和训练超参数，包括 seq/patch、d_model、heads、layers、d_ff、dropout、lr、batch 和 epochs。
- DLinear/Ridge 属于架构对照，不属于 p132 基线调参。
- loss、目标变换、真实周期相位、周期级变量、aa/F10.7、数据增强都属于后续改进系列。
- 任何一个实验系列只改变一个主因素，以免无法归因。
