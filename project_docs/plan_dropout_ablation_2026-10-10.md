# 计划：dropout 口径分裂的跨窗口验证（2026-10-10，景修批准执行）

## 起因

EXP-25（do0.05）与 EXP-26（do0.2）在**同一环境、同一窗口（W1）、同一段长（148 月）**下测出：

| 口径 | do0.05 | do0.2 | 谁更好 |
|------|:---:|:---:|:---:|
| 全步 MAE | 23.37 | **22.87** | do0.2（+2.1%） |
| 滚动 MAE（148月） | **41.63** | 50.29 | do0.05（+17.2%） |
| E_r（全步峰值幅度误差） | **−6.8** | −20.3 | do0.05 |
| 滚动峰误差 | **−20.0** | −32.2 | do0.05 |

即 dropout 在「全步」与「滚动/峰值」两族口径下**方向相反**。这是 SOP 坑 26（口径分裂）的第二个实例。
但**只有 W1 一个窗口**，按项目纪律（W1 筛选 → 优胜者上 W2/W3 验证）不足以定论。

## 目的（一句话）

判定这个 dropout 口径冲突是**跨窗口稳定**，还是 W1 独有的偶然。

## 变量与对照

- **唯一变量**：`dropout` / `fc_dropout`（0.05 vs 0.2）
- 其余参数与 EXP-25/26 逐项一致：seq_len 336 / label_len 48 / pred_len 24 / d_model 128 /
  n_heads 8 / e_layers 2 / d_ff 2048 / patch_len 16 / stride 8 / revin 1 / affine 0 /
  head_dropout 0.0 / individual 0 / train_epochs 50 / patience 100 / batch_size 16 /
  lr 1e-4 / loss mse / activation gelu / seed 2021 / num_workers 0 / features MS / enc_in 3
- 环境：torch 2.8.0+cu128 + RTX A6000，`NVIDIA_TF32_OVERRIDE=0`
- 口径：命令链 train && 补测，正式值取**补测段**（最佳 val 模型）
