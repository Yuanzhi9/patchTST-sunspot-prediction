# PR24 极值预测：负值、周期依赖与平滑训练分析

> 日期：2026-11-21  
> 范围：不新增训练；复用 SC20/SC21/SC24 五 seed 盲测曲线做机制审计。  
> 目标：Cycle 25 谷值/时间、Cycle 26 峰值/时间，曲线轮廓为次主目标。

## 结论

1. 当前 PR24 递归能生成完整周期，但它的真实预测能力有限，主要上限是周期强度
   不可见：没有未来真值更新时，模型只能部分推断下一周期振幅。
2. PR132 direct 的轮廓更平滑，但轮廓和峰时并未稳定优于 PR24 recursive；
   它的预测峰值与真实峰值的跨周期相关约为 0，基本没有跟随周期强度。
3. 负值是真实物理错误，不是评估显示错误。根因是物理反变换后的线性
   输出没有下界，且谷区预测落入训练分布外。评估前 clip 到 0 只改变极小误差，
   不能当作模型改进。
4. 13 月或 Gaussian 后处理平滑能显著降低误差，但这是把预测和真值同时变平滑，
   不能证明“用平滑数据重训”一定有同样收益。
5. 建议把“非负输出”作为正式未来预报前的硬门禁；平滑训练作为单独基线实验，
   不能让它与当前月均基线混成一个分数。

## 容量不足是什么意思

这里的“容量不足”指模型函数表达能力和训练优化能力不够。例如 D16/E1 的 Full
MAE 明显高于 D128，说明隐藏维度或层数太小，连训练期可学习的周期结构都拟合得
更差。它不是数据容量不足，也不是 GPU 内存不足。

五 seed 结果：D128 为 26.83/26.48；D64 为 27.12/27.12，稳定变差；E3 为
26.76/26.39，小于 1% 且 seed 方向不一致；D256 没有超过 3% 的改善。因此 D128
是当前容量平台内较合理的折中，而 E3 的小幅领先不能视为稳定优势。

2026-11-21 补充：D80/D96/D112/D144/D160/D192 的 seed2021 筛选已完成，
D112/D144/D160 已补齐五 seed。三者均未稳定超过 D128；D160 配对 Full/Block
分别变化 +0.143%/+0.034%，seed 方向不一致，因此继续保留 D128。

## 周期依赖的数据

SC20、SC21、SC24 五 seed 中，预测峰与真实峰的关系：

| 方法 | 真峰-预测峰相关 | 峰时绝对误差 | 峰幅误差 |
|---|---:|---:|---:|
| PR24 观测更新 | 0.946 | 7.2 / 12.2 / 4.0 月 | -30.1 / +11.4 / -12.6 |
| PR24 recursive24 | 0.563 | 4.8 / 10.8 / 8.0 月 | -88.8 / +20.0 / -0.65 |
| PR132 direct | -0.005 | 6.2 / 23.2 / 21.6 月 | -121.8 / -13.0 / +28.0 |

表中误差顺序均为 SC20 / SC21 / SC24。

这说明：

- 有真实观测更新时，模型能够从周期已经展开的形态推断振幅；
- 递归没有未来观测时，只能部分保持振幅信息；
- PR132 direct 基本输出一个“平均周期形状”，不能可靠区分强、中、弱周期。

这与太阳周期的非平稳性一致。周期长度、振幅、上升速度和形状都跨周期变化，
最近 132 月 SSN 不能唯一确定下一次峰值。

## PR132 的轮廓与时间

PR132 direct 在三个周期上的曲线 MAE 为 52.15 / 38.84 / 29.82，均高于
PR24 recursive24 的 42.39 / 28.23 / 14.48。峰时和峰幅也不稳定。

因此“PR132 不递归，所以轮廓可能更稳定”没有得到本数据支持。它的优势只是
一次输出完整 132 月且没有块间反馈；代价是一个前向要同时决定整周期的振幅、
相位和持续时间。

## 负值的根因

### 当前代码路径

`PatchTST.py` 的输出头是线性层，`forward()` 末尾没有物理约束。模型输出先经过
RevIN 反归一化，再由数据侧 StandardScaler 逆变换成物理 SSN。

对当前训练窗：

```text
SSN = mean + scale * z
z(SSN=0) ≈ -1.21
```

因此物理负值等价于模型预测 `z < -1.21`。MSE 只降低平均平方误差，并不禁止
某一小段预测越过物理下界。

### 历史修复

Stage 0 使用 MinMaxScaler 时，曾在 `models/PatchTST.py` 输出端加 ReLU。结果把
负值率从 5.56% 降到 0。原因是在 `[0,1]` 归一化空间里，ReLU 的 0 就是物理 0。

2026-05-01 切换到 StandardScaler 后，归一化空间中 `z=0` 对应 SSN≈83。原 ReLU
会变成“所有预测至少 83”，因此被注释。现在代码仍保留：

```python
#x = F.relu(x)
#x = F.softplus(x)
```

所以“当时的负值后来靠改归一化/ReLU 解决”记忆是对的；但那个修复没有自动迁移到
StandardScaler 口径。

### 当前负值数量

| 周期 | PR24 观测更新 | PR24 recursive24 | PR132 direct |
|---|---:|---:|---:|
| SC20 | 0.4 | 0 | 0 |
| SC21 | 0.2 | 1.6 | 1.6 |
| SC24 | 9.4 | 3.0 | 2.2 |

负值主要位于谷区。SC24 的 PR24 recursive 平均每 seed 有 3 个负值月，最差 seed
有 9 个，最低约 -3.50。

直接把负值裁到 0 对总体 MAE 的改变很小：recursive24 在 SC24 仅从 14.483 降到
14.452。因此负值不是主要 MAE 来源，但它破坏物理解释和谷值点估计，正式预测前
必须处理。

### 正确处理顺序

1. 评估报告同时保留 raw 和 physical-clip(0)，raw 不能作为正式交付；
2. 正式未来预测必须在物理空间施加下界，不能在 z 空间加 ReLU；
3. 若要训练期约束，优先物理空间负值惩罚或正确的 `z >= -mean/scale` 变换；
4. 硬 clip 会产生 0 平台，峰谷评价应报区间，而不是把一个 0 当精确谷值。

## 平滑处理的数据证据

零训练、仅对已有预测做后处理的结果：

| 周期 | PR24 recursive raw MAE | 13月 MA | Gaussian σ=3.6 | 24月 FWHM Gaussian |
|---|---:|---:|---:|---:|
| SC20 | 42.39 | 41.72 | 38.82 | 35.71 |
| SC21 | 28.23 | 23.10 | 21.71 | 19.19 |
| SC24 | 14.48 | 11.00 | 10.34 | 8.90 |

Gaussian 平滑后负值明显减少，24月 FWHM 基本清零；13月平均仍有少量残留负值。

但这里是**预测和真值同时平滑**。误差下降的一部分来自把目标本身变得更平滑、
更容易预测，不能直接推出“用平滑数据重训”会有同比例收益。

## 平滑训练是否值得做

值得做，但必须限定协议。

### 方案 S1：平滑目标 + 原始输入

- 输入仍是月均 SSN 历史和时间特征；
- 标签改为 SILSO 官方 13 月中心平滑值；
- 需要把“输入序列”和“目标序列”分离，当前代码把同一 ssn 列同时用于两者；
- 科学价值最高，因为它只改变预测目标，不引入未来输入泄漏。

### 方案 S2：平滑输入 + 平滑目标

- 最接近文献常见“全程用 smoothed SSN”；
- 官方 13 月平滑在 t 月使用 t+6，直接作为输入会在预测起点使用未来 6 个月；
- 历史回测可做“回顾性上界”，不能直接当作真实业务输入。

### 方案 S3：因果平滑

- 使用 trailing 13 月平均或单边 Gaussian；
- 可以真实业务化，窗口末端没有未来泄漏；
- 但峰时会因滤波延迟发生偏移，必须使用同一因果滤波定义真值，不能和官方中心平滑
  混成一个指标。

推荐顺序：S1 → S3 → S2。S2 只能作为回顾性诊断，不能作为当前未来预报方法。

## 平滑实验的公平比较

四线图可以画：

1. raw observed；
2. centered/ causal smoothed observed；
3. raw-trained prediction；
4. smoothed-trained prediction。

但至少报告三种误差：

1. raw 模型 vs raw truth；
2. smooth 模型 vs 对应 smooth truth；
3. 两种预测统一施加同一种固定平滑后，vs 同一 smoothed truth。

否则“平滑模型 MAE 更低”可能只是标签更平滑，而不是模型能力更高。

## 周期依赖怎么解决

按代价和针对性排序：

1. **非负物理后处理/约束**：先做，必须做；
2. **平滑目标训练**：直接改善谷区噪声和周期界对齐；
3. **显式周期相位/强度特征**：加入真实极小值后的 elapsed months、上一周期振幅、
   当前周期累计活动、上升速度；
4. **两阶段模型**：先预测峰幅/峰时/谷时，再生成条件曲线；
5. **物理先验或 mixed model**：Waldmeier/precursor 约束振幅和时间；
6. **scheduled sampling / rollout loss**：缓解递归 exposure bias；
7. **多 seed/多模型集成**：降低单轨迹失效风险，但不能补足缺失信息。

前两项属于当前基线修正；第 3 项以后属于新方法，不应混入“基线”分数。

## 建议

当前不能把含负值的 raw 结果称为正式 PR24 基线水平。建议下一步顺序：

1. 先做无训练的 physical clip 版本，报告 raw/clip 两套；
2. 重新冻结“非负 PR24 baseline”；
3. 同一参数、五 seed，在 SC20/21/24 上补 S1（13月平滑目标+原始输入）；
4. Gaussian σ=3.6 作为并列平滑目标，24月 FWHM 作为更平滑的敏感性版本；
5. 统一平滑后比较两条模型，再决定平滑是否进入正式主基线。

## 文献依据

- Hathaway (2015) 将 13-month running mean 作为传统周期界标准，同时指出
  24-month FWHM Gaussian 的高频泄漏更小。
- Petrovay (2020) 将 13-month smoothed SSN 作为太阳周期预测的标准统计口径之一。
- Xiong et al. (2021) 使用 Gaussian σ=3.6 平滑月均 SSN。
- Wang et al. (2021) 使用 SILSO 13-month smoothed SSN 做整周期留出预测。
- Gerçeker et al. (2025) 同时比较未平滑月均和 13-month smoothed SSN，
  说明两种口径必须分别评价。
