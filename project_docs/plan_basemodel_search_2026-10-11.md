## 二、为什么优先扫 lr / batch_size（依据，不是偏好）

1. **从没扫过**：阶段1 Round 0-7 覆盖的是结构参数（seq_len / patch_len / stride / e_layers / d_ff / d_model / dropout / activation / individual）。
   `learning_rate`（全程 1e-4）与 `batch_size`（全程 16）**从未作为变量出现过**。
2. **训练动态证据（本轮新算）**：最佳 val 出现轮次 —— EXP-26（W1 do0.2）第 **4** 轮、EXP-27（W2 do0.05）第 **5** 轮、
   EXP-29（W3 do0.05）第 **8** 轮、EXP-28（W2 do0.2）第 **16** 轮；前 8 轮 val 曲线震荡幅度约 ±20%
   （EXP-26：0.594 / 0.308 / 0.287 / **0.261** / 0.294 / 0.309 / 0.288 / 0.320）。
   → **"最佳 val 模型"这个正式口径高度依赖"哪一轮运气好"。**
3. **选模口径本身是变量（本轮新算）**：`result.txt` 每次实验两行（训练段=末轮模型 / 补测段=最佳 val 模型）。
   新环境 6 组里 **4 组是"最佳 val 更好"，2 组（EXP-29 / EXP-30，都在 W3）反而是末轮模型更好**。
   → "最佳 val"并不总是更接近测试真值，尤其在 W3（val 段 2008-12~2019-11 与 test 段 2019-12~2025-10 相隔 11 年、跨周期）。
4. **机制上它是"失控分支"的旋钮**：EXP-23-R3 显示轨迹会在"稳 / 失控"之间跳分支，而分支触发与早期误差量级有关——
   lr / bs 正是控制早期误差量级的两个旋钮。

## 四、轮次设计（单变量、3% 门槛、双指标）

### 第 0 轮：训练动态与选模口径体检（不改任何参数）

**做什么**：用基准配置跑一次完整训练，**逐轮记录 train / val / test loss 曲线**，回答两问：
① 最佳 val 轮次与"测试全步 MAE 最低轮次"是否一致？② 训练段（末轮）与补测段（最佳 val）在 test 上差多少？
**要求**：需要保存多轮 checkpoint 或逐轮评估——**若需动代码，先出改动方案报批**（属改训练脚本）。
**为什么排第一**：若选模口径本身在抖，后面所有比较都在噪声里做；先排除这个变量才有意义。

### 第 1 轮：learning_rate ∈ {3e-5, 1e-4（基准）, 3e-4, 1e-3}（3 个新训练）

**可证伪假设**：某个 lr 在 W1 上使全步 MAE 改善 ≥3%，且 block24 恶化 ≤5%。
若全部 <3% → 结论"lr 在 1e-4 附近已到顶"，记入"已扫尽"。
**注意**：lr 与 bs 有耦合（有效步长）→ 本轮固定 bs=16；第 2 轮在**第 1 轮胜者**上做。

### 第 2 轮：batch_size ∈ {8, 16（基准）, 32, 64}（3 个新训练）

**可证伪假设**：同上（全步 ≥3% 且 block24 恶化 ≤5%）。
**注意**：bs 改变梯度噪声量级 → 可能同时改变最优 dropout（第 3 轮回查）。

### 第 3 轮：dropout 回查 ∈ {0.1, 0.2, 0.3}（2 个新训练）

**理由**：dropout=0.2 是在 `lr=1e-4 / bs=16` 下选出的（阶段1 Round 5）。**lr 或 bs 一改，最优正则强度可能跟着变**——
这是最容易漏掉的一环（"调了 lr 却还用着旧 dropout 的结论"）。

### 第 4 轮（备选）：早停 / 选模口径

仅当第 0 轮发现问题时启动。候选：val 用滑动平均判优、加长 val 段、或明确改用"末轮模型"。
**注意**：改选模口径 = 改正式口径，会让历史数字失去直接可比性 → 必须单独成轮并显著标注。

### 不做：label_len 扫描

**代码依据**：`PatchTST.forward(x)` 只消费 `x`（`models/PatchTST.py:85`），`x_dec` 传入即被忽略；
损失只取 `seq_y` 的最后 `pred_len` 步；且 `__len__ = len(data_x) − seq_len − pred_len + 1` 与 label_len 无关。
→ **label_len 对 PatchTST 是空转**，扫它等于白烧机时。
**建议**：只做一次"空转验证"（label_len 改 24 跑一次，结果应与基准**逐位一致**），用一次训练换"以后没人再问"。

## 五、评估口径（含景修问的 block 问题）

**景修问**：进行基模探索时，你想用 block 吗？是不是选 24？

| 口径 | 本轮角色 | 为什么 |
|---|---|---|
| **全步 MAE** | **主指标（筛选用）** | 跨环境最稳（≤4%）、不含回填分支性，是"纯配置"的表征；历史选型一直用它 |
| **block24 无重叠** | **辅证（门槛用）** | 贴真实外推场景；防止"全步变好、轨迹变差" |
| 滚动 MAE | **不用**（仅同环境参考） | 高方差（41.63 / 109.62 / 23.28，4.7 倍）、跨环境差最高 28% → 不可用于选型 |

**为什么调参不拿 block 做主筛**：block 含回填的**分支性**（EXP-23-R3：同一模型换块长会在"稳/失控"间跳分支）。
用它筛选会把"轨迹运气"混进配置选择。**配置比较要干净，用法比较才用轨迹。**

**是否 block=24**：**是**。依据 EXP-23-R3——6 组里一次没翻车（最坏 33.54），六大块长里 minimax 最优；
且它是**可回溯的默认值**（零成本、随时能重算），不构成约束。

**记录粒度（每轮实验必须落盘，缺一项不算完成）**：

```
1. configs/<EXP-ID>_<date>.json（含 num_train，逐窗口核对）
2. logs/<EXP-ID>.log（完整逐 epoch 记录）
3. result.txt 两行（末轮模型 + 最佳 val 模型）
4. 三窗口物理四指标（step0 / 全步 / R² / E_r）+ E_m
5. block24 轨迹 MAE（段长逐条标注：148 / 132 / 71）
6. 最佳 val 轮次（本轮新增必填项）
7. 记录文件（预检回填 + 结论）+ 索引表一行 + commit
```

**双指标门槛（提案，待批）**：全步改善 ≥3%（沿用历史门槛）**且** block24 恶化 ≤5%（新增保护条款）。

## 六、可证伪假设 / 预尸检 / 文献先例 / 坑清单

**可证伪假设**：lr 或 bs 偏离历史值能带来 ≥3% 的全步改善，且 block24 不恶化 >5%。
**无效也算结论**：若全部 <3% → 记"该维度已扫尽，基线在这两个旋钮上到顶"（负结果同样入档）。

**预尸检（最可能变成废物）**：
1. **单种子，3% 门槛可能落在噪声区**（跨环境差 W1 只有 1.1% → 种子级差异可能就在 1-3%）
   → 结论只报"量级/方向"，不报小数点后的胜负；若日后允许补 seed，优先补胜者。
2. **训练动态混淆**：best val 早且 val 曲线震荡 → lr 一变，早停行为跟着变，容易把"训练不足"误读成"lr 更优"
   → **逐轮记录 best epoch 与曲线形态**（第 0 轮正是为此）。
3. **顺手多改变量**：最容易发生在本轮 → 单变量铁律，改动前先填参数对照表。

**文献先例**：lr / bs 是最标准的超参维度，无"报告新方法"性质；PatchTST 原文用 1e-4 量级。
