# 周期头 + 条件轮廓模型实验预登记

> 日期：2026-11-23  
> 状态：E1a/R1-A Oracle 成功；R1B-RAW 已完成；T1 失败；下一步转向新幅度模型
> 主目标：Cycle 25 谷值与时间、Cycle 26 峰值与时间，曲线轮廓为次主目标  
> 当前 baseline：`PR24-SL132-PL36-S18-D128-H8-E2-F2048-DO02-FC02-LR3E4-BS32`

## 1. 核心问题

RQ1：如果峰幅或峰时条件已经正确，PatchTST 能否生成更好的周期曲线？  
RQ2：仅由现有 SSN 计算出的周期特征，能否在完整周期外推中稳定预测下一周期极值？  
RQ3：显式条件融合是否优于当前端到端 24 月递归？  
RQ4：scheduled sampling / rollout loss 能否缩小“真实观测更新”和“预测回填”的差距？  
RQ5：aa、F10.7、WSO 极区场在同覆盖期控制下是否提供额外信息？

## 2. 不属于本计划的内容

- 不把 W 效应直接当作下一周期峰幅定律。W 效应主要是同周期“上升越快、峰值越高”，
  SC26 幅度仍需跨周期前兆或时间序列证据。
- 不在当前 SSN channel-independent 分支上直接追加 F10.7/WSO 列。
- 不将中心平滑末端不可见的 13m 值用于 2026-10 起点。
- 不把 Oracle 条件诊断结果当作可部署预测。
- 不同时修改模型结构、loss、训练方式和外部特征。

## 3. 路线总览

```text
E0 冻结协议
  ↓
E1a Oracle 幅值校正（零训练）
  ├─ 无价值 → 停止单靠峰幅条件救曲线，转查峰时/形状
  └─ 有价值 ↓
E1b 条件融合诊断（真实峰幅/峰时，Oracle）
  ├─ 失败 → 修 fusion，不进入周期头
  └─ 成功 ↓
E2 周期级 Ridge/RF 极值模型
  ├─ 未超过中位数 → 保留 Oracle 机制结论，不接正式预测
  └─ 通过 ↓
E3 真实周期头 + 条件轮廓
  ↓
E4 scheduled sampling / rollout loss
  ↓
E5 aa → F10.7 → WSO 同覆盖期对照
  ↓
E6 冻结并生成 SC25/SC26 正式曲线
```

## 4. 数据与评价口径

### 主数据

- SILSO V2.0 raw 月均 SSN，1749-01–2026-10；
- 评价用 13 月平滑定义峰谷时间，同时保留 raw 月均幅度；
- 当前最终预测起点为 2026-10。

### 历史验证

- 主验证周期：SC20、SC21、SC24；
- 结构确认后的稳健性补测：SC18、SC19、SC22、SC23；
- 每个周期从测试起点前只用历史数据训练；
- 固定超参数后只评价一次外层周期，不用测试集回调模型。

### 主指标

1. 谷时误差，单位月；
2. 峰时误差，单位月；
3. 峰幅绝对误差和相对误差；
4. 谷幅误差；
5. 曲线 MAE/RMSE/R²；
6. 五 seed 均值、标准差、最差 seed 和逐 seed 方向。

任何“改善”必须同时满足：

- 极值方向至少 2/3 主周期一致；
- 不是由单个 seed 主导；
- 曲线 MAE 不恶化超过 5%；
- 不产生新的负值或失控发散。

## 5. 分阶段实验与门槛

### E0：协议冻结（分析任务）

内容：

- 冻结历史周期、指标、seed、50 epoch 和 `clip0`；
- 固定 Oracle 只使用测试周期真值，不进入训练输入；
- 记录所有脚本、输入文件哈希和当前 baseline 曲线；
- 规定失败结果必须保留，不能删 run 重挑。

产物：

- 本预登记文件；
- E1a 脚本与配置；
- 输入完整性检查。

### E1a：Oracle 幅值校正（零训练）

目的：回答“仅把峰幅强制校正正确，能改善多少曲线与谷值”。

对每个历史周期的五条 PR24 recursive block24 轨迹：

```text
scale_i = true_peak / predicted_peak_i
corrected_i(t) = max(raw_prediction_i(t) * scale_i, 0)
```

这里峰幅使用测试周期真实峰幅，因此只作不可部署的上界诊断。

对照：

- raw recursive block24；
- clip0 recursive block24；
- Oracle amplitude-scaled + clip0。

通过门槛：

- 至少 2/3 周期的曲线 MAE 不恶化；
- 平均曲线 MAE 改善至少 5%；
- 谷幅不能出现跨周期方向一致的严重恶化；
- seed 方向不能由单个 seed 主导。

若失败：

- 不启动 E1b 的幅度融合；
- 下一步优先诊断峰时/形状，单靠峰幅不是主要瓶颈。

### E1b：Oracle 峰幅/峰时条件融合

只有 E1a 通过后启动。

输入：

```text
132 月历史 + 真实峰幅 + 真实峰时
```

变体：

- C-A：只给真实峰幅；
- C-T：只给真实峰时；
- C-AT：同时给真实峰幅与峰时。

实现先选一种：

- 条件 MLP 生成 FiLM 的 `gamma/beta`，调制 SSN patch embedding；
- 或直接预测归一化形状，再乘已知峰幅。

通过门槛：

- C-AT 相对 E1a 再改善至少 5%；
- 峰时误差中位数 ≤3 月；
- 曲线改善不是只由缩放造成；
- 消融必须证明条件输入确实进入 SSN 分支。

若失败：

- 保留 E1a 结论；
- 修 fusion 或改用峰时分类/轮廓基函数；
- 不启动 E3。

### E2：周期级 Ridge/RF

样本单位：一个完整周期一条记录。

输入：

- 上一周期峰幅、周期长度、奇偶；
- 当前周期峰幅、上升月数；
- 峰后 24 月衰减比例、斜率、波动；
- 当前相对极小的相位。

输出：

- SC25 谷时；
- SC26 峰时；
- SC26 峰幅。

对照：

- 气候中位数；
- Ridge；
- 浅层 Random Forest。

通过门槛：

- 峰幅 MAE 至少优于中位数 10%；
- 至少 2/3 可测周期方向一致；
- 峰时 ±6 月命中率提高；
- 若只剩峰幅有信号，可进入“幅度头 + 曲线”，但不得声称峰时可预测。

### E3：真实周期头 + 条件轮廓

使用 E2 的预测值替代 Oracle 条件。

要求：

- 采用 E1b 已通过的融合方式；
- 与 PR24、E1a、E1b 分开报告；
- 量化“从 Oracle 到预测条件”的性能损失；
- 不以 Cycle 26 无真值结果调参。

### E4：scheduled sampling / rollout loss

结构冻结后才运行。

| ID | 训练方式 |
|---|---|
| T0 | 当前 teacher forcing |
| T1 | scheduled sampling，预测输入比例逐步增加 |
| T2 | 2–4 block rollout loss |

成功标准：

- 缩小 observed-update 与 recursive 的差距；
- 132 月递归峰幅不劣于 E3；
- 峰时和曲线 MAE 不退化超过门槛；
- 只改善 24 月短期不算成功。

若失败：

- 保留 block24；
- 不因 scheduled sampling 单独失败而否定周期头方案。

### E5：外部指数

顺序固定为 aa → F10.7 → WSO，一次只加一个。

| 数据 | 共同覆盖期 | 允许用途 |
|---|---|---|
| aa | 1868 起 | 周期级和月序列均可，先做单变量 |
| F10.7 | 1947-02 起 | 缩短训练段对照 |
| WSO 极区场 | 1976 起，有效月值止于 2025-12 | 仅历史盲测 |

每个特征都必须同时训练：

```text
同覆盖期 SSN-only baseline
同覆盖期 SSN + 单个外部特征
```

禁止：

- 将外部特征模型与 1749 起 full-history baseline 直接横比；
- 多个外部变量一次性堆叠；
- aa/F10.7/WSO 缺失值统一填 0；
- WSO 缺测端点向未来回填。

若同覆盖期控制没有改善：

- 判定该特征在当前融合方式下无效；
- 不通过更换周期子集挽救结果。

### E6：正式输出

只有通过前置门槛才执行：

- 使用全部 1749-01–2026-10；
- 固定 50 epoch，不按未来数据早停；
- 五 seed；
- 正式输出 `clip0`；
- 同时报中位数、seed 范围和历史留出误差；
- 明确标注 Oracle、不可部署诊断和正式结果。

## 6. 预尸检

1. **Oracle 看似有效，但只是缩放**：曲线仍错，峰幅校正把谷值一起放大。应对：
   分开报告缩放前后 MAE、峰幅、谷幅，不只报峰幅。
2. **条件被模型忽略**：FiLM 或附加通道权重接近零。应对：加“条件扰动测试”，
   改变真实峰幅条件，输出必须随之变化；否则 fusion 判失败。
3. **条件泄漏**：Oracle 真值意外进入训练输入或验证特征。应对：训练/验证只用
   labels 或对应目标周期常量，测试条件只在评价脚本读取，单独泄漏检查。
4. **24 个周期过拟合 Ridge/RF**：换 seed 或换周期就翻转。应对：逐周期留一、
   严格时间顺序、浅模型和气候中位数对照。
5. **峰幅有弱信号但峰时没有**：整套模型只能改善幅度。应对：允许输出“幅度头 +
   轮廓”，不得硬报峰时点值；峰时保留 PR24 或区间。
6. **scheduled sampling 把短期预测带坏**：长期略好、近期明显恶化。应对：
   分别报 24/48/132 月，近期退化超过 5% 不采纳。
7. **外部特征收益来自覆盖期缩短**：1947/1976 起训练天然比 1749 起差，结果却
   看似提升。应对：所有比较强制同覆盖期、同折、同 seed。
8. **WSO 端点缺失导致未来数据回填**：正式预测悄悄使用不存在的极区场。应对：
   WSO 只允许历史诊断；2026-10 正式模型禁止接入。
9. **SC20 强周期再次主导结论**：只针对强周期改善，弱周期恶化。应对：
   先 SC20/21/24 三周期同门槛，再补 SC18/19/22/23。
10. **只看曲线 MAE 掩盖极值失败**：MAE 略好但峰值仍压缩。应对：峰谷时间和
    幅度优先，曲线 MAE 只作辅助。

## 7. 失败应对决策树

| 失败点 | 立即动作 | 禁止动作 |
|---|---|---|
| E1a 无改善 | 停止幅度条件，检查峰时/形状误差 | 继续堆周期头 |
| E1b 条件被忽略 | 做条件扰动测试并修 fusion | 直接进入 E2/E3 |
| E2 峰幅未过中位数 | 保留 Oracle 上界结论 | 把弱信号称成可部署能力 |
| E2 只有峰时有效 | 单独评估峰时条件，幅度退回 baseline | 用峰时模型硬报峰幅 |
| E3 不如 E1b | 报告预测误差损失并调融合 | 用测试周期回调 |
| E4 近期退化 | 保留普通 teacher forcing | 用 132 月均值掩盖短期失败 |
| 外部特征无增量 | 记录负结果并停止该变量 | 改用不同周期子集重挑 |
| 数据缺失过多 | 保留 NaN/mask 或停止该变量 | 插值出长段或填 0 |

## 9. 文献依据

- Xiong et al. (2021) 已采用“前兆回归预测峰值 + 改良 HWR 轮廓”，支持两阶段结构，
  但 HWR 单峰和少量周期样本限制了外推。
- Kalkan et al. (2026) 使用机器学习、集成学习和 Waldmeier 关系预测 SC26，
  说明周期级模型是现实对照，但不同方法仍给出不同时间和幅度。
- Soman & Sabarinath (2026，预印本) 结合 aa 前兆和 DTW 历史轨迹预测峰值与轨迹，
  是本研究最接近的路线；因尚未正式同行评议，只能作方法参照。
- Petrovay (2020) 指出前兆方法总体上优于纯时间序列外推，但周期本身并非完全
  同质统计单元。
- Ben Taieb et al. (2012) 及后续多步预测研究表明 direct/recursive 没有普遍赢家，
  取决于序列和模型设定；必须在本任务上实测。
