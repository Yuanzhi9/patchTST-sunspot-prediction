# 画图规范与图册（Figure Guide）

> 创建：2026-08-20。用途：本项目所有画图的标准与方法论沉淀，服务"复盘消化、讨论叙事、论文图库、数据审计"。
> 景修要求：之后的论文画图要多样、特征鲜明——每张图必须有目的、有故事、图类型选择有理据。

---

## 1. 画图的四个目的（2026-08-20 三思定稿）

1. **景修复盘消化**——数字→图形，思维工具。14 个实验的数字堆在文档里，人脑靠图形才能"看见"权衡线、规律、崩塌点
2. **开学讨论叙事支撑**——向学姐学长导师讲"我们发现了什么"，一张好图胜过十段文字
3. **论文图库草稿**——单种子限制下现在图不直接进论文，但是方向验证 + 构图草稿
4. **数据二次审计**——画图过程（重新推理+对拍）= 对 result.txt 记录的独立复核。图能画对，说明记录可信

## 2. 画图铁律（7 条）

1. **每张图必须回答一个"故事问题"**——没故事的图不画
2. **数据源=对应实验 checkpoint 重新推理**；图内 MAE 与 result.txt 已记值**逐位一致才出图**（不一致=bug，先修再画）
3. **变换模型带同一 target_transform**（坑 25）
4. **色盲友好色板**：蓝/橙/灰三族，弃红绿（学术期刊黑白打印可读）
5. **caption 自包含**：口径（月均/最佳模型）/窗口/种子（n=1）/指标定义/单种子警示——不看正文也懂
6. **single seed 标注在图内**
7. **学术风**：白底/英文/dpi300/字号 8-10pt/仅横向浅灰网格/去顶右边框

## 3. 图表选择方法论（多样性 + 特征鲜明）

| 故事类型 | 图类型 | 实例 | 选择理由 |
|---------|--------|------|---------|
| 连续变量规律 | 折线 | E2 幂次规律、E5 提前期剖面 | 连续自变量，趋势一目了然 |
| 权衡/分布 | 散点 | E1 性能空间、E3 loss 权衡 | 二维关系 + 帕累托前沿，点=单次实验（无需误差棒） |
| 分组对比 | 分组柱 | E4 block | 离散类别对比；⚠️ 无误差棒时须标 single seed，bootstrap CI 出来后补误差棒 |
| 矩阵规律 | 热力图 | 候选（变换×指标） | 行列双维度，颜色编码改善/恶化 |
| 机制/流程 | 概念图（框+箭头） | E7 | 因果关系非数值，期刊风格简洁框图 |
| 双口径对比 | 双栏示意图 | E6 | 同一对象两种评分的并置 |

**选择原则**：图类型服务于"这个故事最直观的呈现方式"，不反过来。

## 5. 论文图的未来路线（与现在图的区别）

- **现在图**：single seed、无误差棒 → 服务复盘+讨论
- **论文图**：多种子 mean±std + bootstrap CI、正文 3-4 张 + 补充材料
- **关系**：现在图是论文图的"故事验证稿"——故事对、图类型对，数据升级（多种子重跑）后即论文图。这就是"多样、特征鲜明"的落地路径：先立故事，再升数据

## 6. 图文件命名规范

```
fig_<系列>_<内容>_<日期YYYY-MM-DD>.png
例: fig_E1_perf_scatter_2026-08-20.png
    fig_W1_roll_vs_block_2026-08-15.png
带日期（可追溯），输出到 plots/
```
