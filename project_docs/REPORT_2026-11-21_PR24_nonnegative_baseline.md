# PR24 非负基线预测能力报告

> 日期：2026-11-21  
> 目标：判断冻结的 PR24 基线能否承担 Cycle 25 谷值和 Cycle 26 峰值的预测任务。

## 结论

PR24 recursive block24 在非负口径下能生成完整周期，曲线上与真实值高度相关，
且三个周期都优于 persistence。但它还没有达到“可稳定预测峰谷”的标准：

- SC21、SC24 的谷时五 seed 全部命中 ±6 月；SC20 为 3/5。
- 峰时只有 SC20 为 3/5 命中；SC21、SC24 都只有 1/5。
- 峰幅跨周期方向不稳定：SC20 低估 88.8，SC21 高估 20.0，SC24 误差 -0.65。

因此 PR24 可以作为曲线轮廓和谷值时间的基线候选，但**不能把当前峰幅/峰时点值直接
当作 Cycle 26 的正式预测**。这正是进入真实未来预测前必须接受的能力上限。

非负门禁消除了物理非法值，但对总体 MAE 只改变约 0.1–0.3%，再次说明它是发布门禁，
不是模型能力提升手段。

### 集合预测

五 seed 中位数与经验区间的结果见 `pr24_nonnegative_ensemble_metrics.csv`。
SC24 的 80% seed 区间覆盖率约 22%，SC21 约 28%，SC20 约 11–14%；seed 区间不能解释
模型偏差，不能当作可靠的预测置信区间宣传。

## 对目标任务的直接判断

1. Cycle 25 谷值月份：有希望。SC21/SC24 五 seed 均命中 ±6 月；但强周期 SC20
   仍有 3–8 月偏差。
2. Cycle 26 峰值月份：当前不足。两个周期 1/5 命中，只有 SC20 稍好。
3. Cycle 26 峰值幅度：当前不足。强、中、弱周期误差方向不一致。
4. 完整曲线：可作为轮廓输出，但必须同时显示 seed 范围和峰谷误差，不能只报 MAE。

## 边界

- recursive24 不使用测试期真实值，是真实外推路径。
- observed-update 每 24 月使用真实观测，只作“观测更新值多少钱”的参照。
- 五 seed 只描述训练随机性；三个周期不足以估计跨周期总体置信区间。
- 峰谷采用 raw 预测曲线的 13 月中心平滑定义，与 raw 月度曲线同时展示。
