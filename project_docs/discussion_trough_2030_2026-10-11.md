## 二、我们已经知道的（依据，全部可查）

**依据 1：三个回测窗口的谷点误差（EXP-24，月均口径，阶段1 配置）**

| 谷点 | 真实谷值 | 滚动：时间/幅度 | block24：时间/幅度 |
|------|:---:|:---:|:---:|
| W1 1996-10（后侧 12 月） | 0.7 | +1 月 / **−6.2（负值）** | 无谷 / +3.5 |
| W1 2008-08（完整 ±12 月） | 0.3 | **无谷 / −194.5（崩塌）** | −3 月 / +15.0 |
| W2 2009-08（后侧 12 月） | 0.0 | 无谷 / **+55.6** | +1 月 / +31.5 |
| W3 2020-02（后侧 12 月） | 0.2 | +9 月 / **−6.8（负值）** | +2 月 / −2.6 |

**要点：幅度必崩（两个方向都有：负值、+55），时间半个可用（block 为 −3/+1/+2 月）。**

**依据 2：本轮新证据（EXP-23-R2，新环境 do0.2）**

- W2 起谷**抢跑**：真值 1,1,1,1,1,3,6,6,0,7,8,7；滚动报 23-53 → 模型认定"谷后必升"，把上升提前 1-2 年。
- W3 起谷**压到负值**（滚动 −7~−9）。
- W1 末谷**漂上天**（滚动 90-195，真值 0-10）。
- 伤害主因是"逐月反复回填"：滚动比 block 差 1.7-2.1 倍，而单次前向的步距代价只有 1.45-2.37 倍。

**依据 3：谷区在数据里有多稀有**（全数据 3321 月）

| 阈值 | 月数 | 占比 |
|------|:---:|:---:|
| SSN < 1 | 111 | 3.3% |
| SSN < 3 | 176 | **5.3%** |
| SSN < 10 | 398 | 12.0% |

**依据 4：各窗口模型"看过多少个周期"不同**

| 窗口 | 训练段 | 没见过的周期 |
|------|--------|-------------|
| W1 | 1749-02~1985-07 | 22-23 |
| W2 | 1749-02~1997-11 | 23 |
| W3 | 1749-02~2008-11 | **24 与 25（含唯一的"小周"样本 24）** |
| 阶段3 真实任务 | 1749-02~2025-10 | 无（全部看过，但要外推到没有真值的地方） |

→ 含义：W3 回测里模型没见过 24 周（146 的小周），而真实任务里见过。
对 26 周（预期小周）可能是利好，但**方向不确定，不能拿 W3 的数直接外推 26 周的难度**。

## 三、为什么难（推理，三条机制）

1. **目标函数不爱谷**：MSE 账本里谷值低（0-10）、样本少（<3 占 5.3%），梯度贡献被峰区淹没。
   这是"峰值压制"的镜像：模型把极端值往中间拉，峰被压低、谷被抬高（或压成负值）。
2. **归一化与形状先验**：RevIN 逐窗归一化，模型看到的是"形状"。谷区形状 = 长期平坦，
   而训练集里"平坦之后跟着上升"是常态 → 模型提前发动上升（W2 抢跑），或反过来把平坦段外推成负值（W3）。
3. **自回归放大**：逐月回填把误差当输入，本轮实测滚动比 block 差 1.7-2.1 倍（见 EXP-23-R2）。

**关键不对称（决定了对策方向）**：

> 谷**时间** = 找趋势拐点 → block 能到 ±3 月（可用）；
> 谷**幅度** = 报极值 → 系统性崩（不可用）。
> 所以对策的主线应该是：**保时间、缩幅度、给区间**，而不是硬报一个谷值数字。

## 四、计划（候选方案，按代价从小到大；需景修选）

### A 组：报告口径改造（零训练成本）

- **A1** 不报单月谷值，改报"谷窗口"（如 ±6 月的 SSN 均值）——抹掉单月噪声。
- **A2** 谷时给区间（bootstrap 复采样 / 多起点轨迹集的分布），不报单点。
- **A3** 幅度报"量级 + 相对误差"，不报绝对 MAE（谷值本身 0-3，绝对误差天然好看，是假象——EXP-24 预尸检第 4 条已写）。

### B 组：推断方式改造（零训练成本，改动仅脚本）

- **B1** block_size 扫描（6/12/24）+ 换起点（从峰后 N 月开始跑轨迹，而非固定从窗口起点）。
- **B2** 自适应块长：谷区用小块（6），稳定段用大块（24）。
- **B3** 多起点集成：不同起点/块长跑多条轨迹，取中位数——抑制单条轨迹的漂移（W1 漂上天、W3 负值都是单条轨迹的病）。

### C 组：训练目标与结构（要重训，按红线须先出方案报批）

- **C1** 低值加权 loss（wmse 的镜像，谷区加权）。⚠️ 代价已知：wmse 证明了这类加权是"零和"——一处改善、另一处恶化。
- **C2** 输出非负约束。⚠️ **历史坑见下**，必须做对位置。
- **C3** 训练时对齐推理口径：scheduled sampling（训练时按比例把输入里的真值换成模型自己的预测）或多步 rollout loss。
  这条针对的就是"回填伤害"的根因（exposure bias），是治本方向；代价是训练代码改动。

### D 组：问题重定义（新实验）

- **D1** 谷时当**分类**任务（逐月判"是不是极小值"），与"时间可用、幅度崩"的证据吻合。
- **D2** 输入加物理先验（`cycle_phase` / `year_norm` 现成在 CSV 里，当前 enc_in=3 没用）。景修已指定另开讨论。
- **D3** 训练改用 13 月平滑口径（重启 Q9）：与官方周期界对齐，谷区噪声小；代价是全部历史数不可比。

### E 组：混合

- **E1** 物理方法（师兄 M4 Waldmeier）定谷时 + 模型给形状/幅度区间。注意 M4 谷值能力本身未验证过。

### ⚠️ 历史坑：那行被注释掉的非负约束

`PatchTST_supervised/models/PatchTST.py:97-98`

```
#x = F.relu(x)        #2026.04.09添加     04.16改成softplus
#x = F.softplus(x)    #2026.05.01修改，注释掉
```

**诊断**：那一行作用在 **StandardScaler 的 z 空间**，而 z = 0 对应物理 SSN ≈ 83
（训练段均值 82.9 / 83.2 / 83.5，标准差约 68）。所以当时的"非负约束"实际等价于
**"所有预测 ≥ 83"**——结构性地错，被注释掉是合理的。

**要做 C2，正确位置是反归一化之后**（物理空间），或把阈值设在 z = −1.22（= SSN 0）。

## 五、预判失败与备用方案（每个方案都要有退路）

| 方案 | 最可能怎么失败 | 备用 |
|------|---------------|------|
| A1/A2 | 谷窗口均值同样被漂移污染（W1 末谷 block 也 +15） | 退到"只报谷时区间 + 幅度只给量级" |
| B1/B2 | 块长在谷区不单调（W3 的 block 前/后 4.8x） | 只在谷区用多起点集成（B3） |
| B3 | 多起点轨迹方差大，中位数被个别崩塌轨迹带偏 | 改用截尾均值，并报告轨迹散布 |
| C1 | 谷区变好、全步与峰变差（wmse 的镜像代价） | 双指标并列报告，按阶段3 用途取舍（判定标准③） |
| C2 | 硬约束把谷区抬到 0 以上，而真值 0-3 → 反而变差 | 改成软约束（仅截断极端负值，如 < −5 才截） |
| C3 | 训练不稳/收敛慢（现有 50ep 已在第 4 轮附近取到 best val，说明易过拟合） | 保留 block 策略，只做 B 组，C3 暂缓 |
| D1 | 正样本太少（1/71），分类学不动 | 用"局部极小"软标签（与邻月的差值）或改成序数回归 |
| D3 | 口径变更 → 全部历史数不可比、决策依据断裂 | 双口径并行报告一段时间，不切换主口径 |
| 全部 | 单种子，3% 级差异不可信 | 关键方案跑 2-3 seed（景修 10-11 指示：现阶段不考虑 → 则结论只能限"量级级"差异） |

## 六、成功标准（先定，再跑）

- 谷**时间**：误差 ≤ ±3 月为优，≤ ±6 月可接受（基准来自 EXP-24 的 block ±3 月）。
- 谷**值**：报告"预测谷值 / 真谷值"的量级比；不以绝对 MAE 论好坏。
- **不许出现负值**（物理下限）。
- 必须同时报全步与峰值，证明没有"拿谷区换全域"。
