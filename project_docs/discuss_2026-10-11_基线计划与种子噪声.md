## 一、"三步修法"的具体计划（上一轮只给了骨架，这里落细）

### 第 1 步：量种子噪声底线（独立任务，编号 `EXP-B00`）

| 项 | 内容 |
|---|---|
| 目的 | 把"门槛"从**拍的数字**变成**量出来的数字**；回答"3% 够不够" |
| 配置 | 现基线配置（EXP-18-5b / GPU 复核 EXP-26 同参数），**不动任何变量** |
| 因子 | seed × 窗口。seed ∈ {**2021（已有，直接复用）**, 2022, 2023}；窗口 W1/W2/W3 |
| 新增训练 | **2 个新 seed × 3 窗口 = 6 次**（约 15 分钟） |
| 命名 | des 必须**逐 seed 不同**：`EXP-B00-s2022` / `EXP-B00-s2023`（checkpoint 目录名含 des → 不会互相覆盖） |
| 每点记录 | 全步 MAE / step0 / R² / E_r / E_m / **block24 MAE**（段长逐条标注） |
| 产出 | 每窗口 `mean ± std`（N=3）→ σ_seed（**分别对 全步 与 block24 两个指标**算） |

### 第 2 步：用 σ 定门槛（门槛表）

```
门槛_全步(W) = max(3%,  2 · σ_seed,全步(W))
门槛_block(W) = max(5%,  2 · σ_seed,block(W))
```

- **按窗口分别定**（W2 谷区难度与 W1/W3 差一个量级，不共用一个门槛）。
- σ 由 3 个样本估计，本身有不确定性 → **保守取 `max(σ 估计, 极差/2)`**。

### 第 3 步：胜者复核

- 每轮胜者补 2 个 seed（凑 N=3），报 `mean ± std`；**只有 mean 差 > 门槛才采纳**。
- 且必须 **≥2/3 窗口同向**（单窗口赢不算）。

### 第 1–3 步的失败预备方案（景修问的"有没有失败的预备解决办法"）

| 失败情形 | 判据 | 预案 |
|---|---|---|
| **σ 太大** | σ_全步 > 5%（→ 门槛 >10%） | 说明单种子根本不可用于比较：① 所有候选一律跑 3 seed（成本 ×3，仍约 1.5 小时/轮）；② 或改用"同 seed 跨窗口一致性"作主判据（不再比单点数值） |
| **σ 很小** | σ_全步 < 0.5% | 门槛回到 3%，seed 数可降回 1（省时间）；这本身是结论：该配置对种子稳定 |
| **σ 估计不可靠** | N=3 的 std 波动大 | 用 `极差/2` 或加跑 2 个 seed（N=5，+10 分钟） |
| **某窗口 σ 异常大** | 如 W2（谷在最前） | 该窗口单独放宽门槛，或该窗口只做定性判断（方向对不对），不参与数值排名 |
| **多 seed 命名冲突** | checkpoint 互相覆盖 | 已核实：checkpoint 目录名含 `des` → 每 seed 用不同 des 即隔离；写进预检表 |
| **时间超预算** | 超过 1.5 小时 | 6 次训练约 15 分钟，正常不会超；若超，先停下汇报 |
| **整体不可行** | 结论落在噪声里、反复无定论 | 退到"接受现配置即基线"（见失败处理表最后一行），把精力转到阶段2/3 |
