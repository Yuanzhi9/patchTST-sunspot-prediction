## 六、Phase 3：实验验证（2-4 周）

> ⚠️ 实验列表在 Phase 2 完成后制定。以下为框架规则。

### 执行规则

- 一次只跑一组对照（如"基线 vs 加了斜率特征"），当天分析完当天决定下一步
- 每个实验向 `result.txt` 追加标准化记录行
- 负结果同样记录——不是所有实验都要"成功"才算有价值
- 不理想的结果也要分析原因，这是"边界刻画"的一部分

### 预设停止条件

避免无限调参。满足任一条件即停止实验、转写作：

| 条件 | 动作 |
|------|------|
| 任何配置 MAE < 10 | 有发表价值，重点验证稳定性和泛化能力 |
| 全组物理特征 MAE 仍 > 15 | 确认"数据驱动 + 物理特征"无法接近 M4。结论本身有价值，转写作 |
| 实验超过 8 组仍无 >10% 改善 | 信号耗尽，整理现有结论 |

## 九、附录：文献阅读工具模板

以下为配合 Phase 0 使用的阅读方法论。从旧版研究计划迁移。

### 三遍读法

| 遍数 | 时间 | 做什么 | 目标 |
|------|------|--------|------|
| 第一遍 | 5-10 分钟 | 标题+摘要 → Introduction 最后一段 → Conclusion → 扫图和表 | 判断这篇要不要细读 |
| 第二遍 | 30-60 分钟 | 跳过公式和证明，仔细读文字描述和图表 | 能向别人讲清楚方法的核心思路 |
| 第三遍 | 只在核心论文上做 | 想象自己实现论文代码，推公式 | 挖出没说清楚的细节 |

对于 Phase 0 必读文献：Petrovay 做第一遍，PatchTST / DLinear 和各篇 DL+sunspot 论文做第二遍。

### 常见阅读困难及对策

| 遇到什么 | 怎么办 |
|----------|--------|
| 整段看不懂 | 跳过。标记"卡住的地方"，先往下走 |
| 公式看不懂 | 跳过。理解思想就行 |
| 术语不认识 | 记下来，查一下。查了还不懂就标记 |
| 读完不知道说了啥 | 正常。先填"卡住的地方"，回来再扫一遍 |
| 自评全是 1-2 分 | 正常。如实填 |
