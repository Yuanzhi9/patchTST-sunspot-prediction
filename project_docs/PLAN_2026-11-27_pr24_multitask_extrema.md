## 3. 标签口径

对每个样本的预测起点 `t0`：

```text
A_next_peak_raw  = 下一次官方周期主峰的 raw 月均峰幅
m_next_peak      = 从 t0 所在月到下一次官方 13m 主峰的月数
m_next_trough    = 从 t0 所在月到下一次官方 13m 谷时的月数
cycle_length     = 当前官方 13m 谷到下一官方 13m 谷的月数
```

说明：

- 时间标签使用 13m 平滑官方周期边界；
- 幅度标签使用 raw 月均峰幅，不与 13m 幅度混算；
- `t0` 之后的数据只进入训练标签，不进入输入；
- 下一次事件未知时使用 mask，不填 0；
- 双峰或多峰不能硬分类成另一个新任务；第一轮使用官方主峰，双峰敏感性另测。

## 4. 实验阶梯

### A0：零训练标签审计

产物：

- 每个 fold/flag 的事件标签覆盖率；
- 标签与预测起点的对齐表；
- 事件落在 24 月窗口内外的比例；
- 13m/raw 口径边界检查；
- 未来数据不进入输入的静态审计；
- 双峰周期和标签缺失清单。

通过条件：

- 所有日期按月对齐，无 off-by-one；
- 每个训练 fold 的峰幅和峰时标签覆盖率均为 100%；
- 最近端点缺失标签有 mask；
- 不把事件标签加入 `batch_x`；
- 可复现实验输出文件与 SHA。

### A1：冻结基线

直接使用现有 PR24 reference baseline，保持数据、切分、MSE、参数和输出不变。

### A2：峰幅单头

```text
24 月曲线 + 下一主峰 raw 峰幅
```

只增加一个辅助目标，先做 seed2021、fold 1–4 筛选。

### A3：峰时单头

```text
24 月曲线 + 到下一主峰的剩余月数
```

与 A2 分开，不共享辅助头参数作为默认设计。

### A4：谷时单头

```text
24 月曲线 + 到下一谷的剩余月数
```

用于检验低收益假设；不因基线谷时已经较好而跳过最终尝试。

### A5：全量联合头

```text
24 月曲线
+ 峰幅头
+ 峰时头
+ 谷时头
```

固定归一化后的初版权重；即使单头失败，也按要求完成此组合。

### A6：权重与稳健性

至少比较：

- 固定权重；
- 不确定度权重；
- 梯度归一化或冲突消解方案中的一种。

通过单头筛选后做五 seed，并在 SC20、SC21、SC24 时间顺序盲测上评价。

## 5. 损失设计

初版：

```text
L = L_curve
  + lambda_A * Huber(A_hat, A)
  + lambda_p * Huber(m_hat_p / 12, m_p / 12)
  + lambda_v * Huber(m_hat_v / 12, m_v / 12)
```

规则：

- 曲线损失是主任务；
- 各任务先归一化到可比尺度再乘 lambda；
- mask 后的辅助损失按有效样本数归一；
- 早停和 checkpoint 选择只看内层验证曲线损失；
- lambda 只在内层验证选择，禁止用外层周期测试调权重；
- 不确定度权重和 GradNorm 类方法放在 full 组合之后。

## 6. 评价

主评价：

- PR24 observed-update；
- PR24 recursive block24；
- 曲线 MAE/RMSE/R²；
- 峰幅绝对误差与相对误差；
- 峰时绝对误差与 ±6 月命中率；
- 谷时绝对误差；
- 五 seed 均值、标准差、最差 seed 和方向一致性。

采纳门槛沿用：

- 峰时或谷时至少 2/3 周期不劣，且 ±6 月命中率提高；
- 峰幅至少 2/3 周期改善，单周期恶化不超过 10%；
- 三周期平均曲线 MAE 不恶化超过 5%；
- 改善不能由单个 seed 主导；
- 辅助头改善必须分别报告单头与 full 组合，不能把 full 组合收益自动归因给单头。

## 8. 失败条件与预尸检

最可能的失败原因：

1. 峰幅/峰时头只学到历史平均，没有跨周期信息；
2. 辅助任务梯度和曲线任务冲突；
3. 双峰标签不稳定；
4. teacher-forced 辅助监督不能缩小 recursive 推理差距；
5. full 联合头改善只在单 seed 或单周期出现。

若 full 组合失败，保留完整实验和失败证据，不用“再来一个权重搜索”掩盖缺少预测信号的问题。
