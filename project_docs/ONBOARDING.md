## 阶段1结论（2026-08-14，别重复劳动）

1. **最终配置**：sl336, pl16/s8, el2, df2048, dm128, nh8, **dropout=0.2**, gelu, ind0, MS, 50ep, seed=2021
2. **主指标**：W1+W2 平均全步 MAE=21.33；W1=22.62（Cycle23），W2=20.03（Cycle24），W3=21.11（Cycle25部分）

## 探索期结论（2026-08-15，Stage 9，别重复劳动）

> 阶段1 之后、开学之前的自主探索：数据表示/训练目标/使用策略三系列 14 个实验。
> ⚠️ **判定标准 6 项待景修批注**（`project_docs/judgment_criteria_discussion_2026-08-15.md`）——
> 批注前所有"最佳"都是 AI 暂定，不得当正式结论引用。

1. **机制4（新识破）**：右偏分布是滚动误差爆炸的主要放大器——所有目标变换让滚动 MAE 改善 45-56%（基线 50.41 → pow23 22.13）
2. **机制3 证伪**：RevIN 不是峰值压制元凶，是滚动稳定性支柱（revin=0 滚动崩溃）
3. **loss 最佳候选 wmse_th**（阈值加权，tau=1.5 即 SSN>185，占训练段 9.4%）：滚动峰 -6.2（改善77%）、滚动 33.92（改善33%）、低值损伤最小
4. **外推策略最佳候选 block24 无重叠**：三窗口优于滚动 44-59%（W1 21.29 / W2 27.28 / W3 23.75）；重叠12月反而更差
5. **口径分裂教训**：全步（125独立窗口）与滚动/block（自回归轨迹）结论常相反；阶段3 是外推场景，以滚动/block 口径为主
6. 组合实验队列（判定批注后）：C-1 pow23+wmse_th、C-2 block+wmse_th，按"新基线+单变量"框架
7. 线 B 完成：`phys_params_survey.md`（Xiong四参数+aa）、`b3_m4_comparison.py`（M4对拍，⚠️ 结论标注AI判断、景修持保留）、`discussion_agenda.md`

## 今天犯的错，你不要再犯

| 错误 | 正确的做法 |
|------|----------|
| 用 run_sunspot_fixed.py 跑实验 | **必须用 run_longExp.py 命令链模式**（SOP §4） |
| 并行跑两个训练进程 | **串行铁律**。8GB 无 swap，并行=OOM+SSH断连（08-12 事故） |
| python 不带 -u 跑训练 | 输出缓冲会让你以为卡死。必须 `-u` |
| 进程不加 nohup/setsid | SSH 断连会杀掉训练。统一用 `scripts/launch_experiment.sh` |
| 测试口径混用 | **正式实验=最佳val模型口径（train&&补测命令链）**。最终模型口径（一次性train→test）在 50ep 下过拟合导致结论反转，已废弃 |
| 没确认参数就训练 | 跑之前填 SOP §1 预检表（假设/预尸检/参数对照表/成功标准） |
| 改了评估/推理代码没回归 | 改动后用已知数值对拍（如 EXP-14 9.08/23.87 锚点） |
| 跑完实验不立刻落盘 | 五件证据链（checkpoint+npy+result.txt+eval+记录）齐全才进下一个 |
| commit 只 add 了部分文件 | commit 前 `git status` 核对；npy 是证据必须入库 |
| 替她定方向 | 只分析、给建议，等她决定 |
| 结论表述简化过度（如"不敏感"） | 敏感/不敏感必须精确到区间和百分比，带单种子标注 |
| 变换管线只改一半（只改逆变换漏正变换） | 变换三处（正/逆/回填）一次改齐 + 往返恒等+锚点回归双验证（08-15 pow07 荒谬值教训） |
| 新评估脚本没有退化自检 | block 脚本必须自检"block=1 逐位等于滚动"（08-15 抓到 z_block 截断 bug） |
| 变换模型的评估/画图漏传 target_transform | 图内 MAE 必须与已记值一致才出图（08-15 多模型图 FAIL 教训） |
| 全步与滚动/block 口径混用 | 按使用场景选口径；阶段3 以滚动/block 为主；全步保留为"远期退化体检" |
