# p132 失效原因与冻结定义

仓库内摘要见 `research_2026-11-20_p132_failure_and_update_cadence.md`；完整便利副本见 `/output/p132失效机制核查_2026-11-20.md`。

核心结论：

- p132 的主要限制是长时距信息不足、真实周期振幅/持续时间不可由最近 SSN 唯一确定，以及 MSE/重叠窗口/选模方式共同造成的平滑化；
- PatchTST 并非已被证明“不适合太阳黑子”，但当前大模型和普通调参没有超过简单 Ridge 对照；
- 当前配置是 26 组网格内的最佳候选，不是全局最优；
- 现有五折第 1–4 折训练包含留出块之后的数据，属于未来感知的块补全，不是纯未来预报；
- “冻结”指锁定数据快照、特征、归一化、切分、超参数、checkpoint 规则、推理更新频率和指标，而不是禁止一切后续修改；
- p24 P36 候选应使用无歧义名称，例如 `BASE-2026-11-M-P24-PL36`，避免与 p132 的 patch_len=36 混淆。
