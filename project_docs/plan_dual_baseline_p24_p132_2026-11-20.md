# 双基线预登记：p24 递推基线与 p132 整周期基线（2026-11-20）

> 状态：景修已授权执行；本文件在训练前落盘，后续不得据测试结果改写选择规则。
> 工作线：p24 属 `BASE-2026-11-M`；p132 另建工作线 `BASE-2026-11-M-P132`。
> 数据快照：`sunspot_with_cycle_monthly_2026-10.csv`，1749-01 至 2026-10，3334 月。

## 一、要解决的问题

分别寻找：

1. `pred_len=24` 的 PatchTST 最佳可复现基线，用法是无重叠 block24 递推；
2. `pred_len=132` 的 PatchTST 最佳可复现基线，用法是一次直接输出约一个太阳周期；
3. 两者分别冻结后，在**同一外层折、同一日期范围、同一物理 SSN 口径**上比较整段曲线。

这不是寻找“一个共享最优参数”。p24 与 p132 的输出头、训练目标和有效样本结构不同，必须分别调参、
分别冻结、分别报告证据边界。

## 三、p24 补强（`BASE-2026-11-M`）

### 3.1 已有锚点

P36 暂定配置：

```text
seq_len=132, pred_len=24, patch=36/18
lr=3e-4, batch=32, dropout=fc_dropout=0.2, heads=8
d_model=128, e_layers=2, d_ff=2048, epochs=50
```

三 seed Full/Block24 = 26.83 / 26.46。

### 3.2 本轮新增

1. 完成 `lr ∈ {3e-4, 1e-3} × batch ∈ {16, 32}` 的三 seed 2×2 对照；
   已有三个角，补 `lr=1e-3, batch=32` 的 seed 2019/2020/2021。
2. 最终候选补 seed 2022/2023。
3. 生成逐提前期 MAE 与全滑窗误差分布辅图。

### 3.3 选择规则

- 默认保留现有 P36 `lr=3e-4/bs32`；
- 只有另一组合在三个 seed 的 Full 与 Block24 均同向更优，且平均改善达到 3%，
  才改变默认配置；
- 新 seed 若使五 seed 均值恶化超过 3%，标记“候选不稳定”，不自动冻结；
- 稳定性图只解释误差分布，不据单张图改选参数。

## 四、p132 独立基线（`BASE-2026-11-M-P132`）

### 4.1 为什么使用独立 fold spec

当前 p24 fold spec 的内层验证为 132 月。p132 在每个内层验证块中只能构造 1 个完整目标窗口，
checkpoint 选择方差过大。

新建 `configs/cv5_folds_p132_2026-10.json`：

- 外层五块与 p24 完全相同；
- 每个训练块前 507 月为 inner train（末块 506）；
- 每个训练块后 160 月为 inner val；
- 该长度兼顾两件事：p132 每块有 29 个重叠验证窗口；`seq_len=336` 时每块仍有约 40 个训练窗口，
  不会因 `batch=32 + drop_last=True` 变成零个 batch；
- 训练窗口不得跨段，外层块不参与训练与早停；
- scaler 仍只用 inner train 拟合。

### 4.2 固定骨架

```text
pred_len=132, label_len=48
d_model=128, e_layers=2, d_ff=2048
dropout=fc_dropout=0.2, head_dropout=0
revin=1, loss=mse, lradj=type3, pct_start=0.3
epochs=50, patience=100, seed=2021（筛选阶段）
```

`label_len` 在主模型前向中不参与计算，只保留接口兼容。

### 4.3 分阶段搜索

#### P132-S：结构和历史长度

| 配置 | seq_len | patch/stride |
|---|---:|---:|
| `B26M-P132-S132-P16` | 132 | 16/8 |
| `B26M-P132-S132-P24` | 132 | 24/12 |
| `B26M-P132-S132-P36` | 132 | 36/18 |
| `B26M-P132-S336-P16` | 336 | 16/8 |
| `B26M-P132-S336-P24` | 336 | 24/12 |
| `B26M-P132-S336-P36` | 336 | 36/18 |

固定 `lr=3e-4, bs=32, seed=2021`。按周期级 MAE 保留 top-2。

#### P132-L：learning rate

在 top-2 上比较 `3e-5 / 1e-4 / 1e-3`；`3e-4` 为已有锚点。
固定 batch32，保留每个结构的 best lr，再比较两个结构。

#### P132-B / D / H

在阶段冠军上分别做：

- batch：16 / 64（32 已测）；
- dropout：0.1 / 0.3（0.2 已测）；
- n_heads：4（8 已测）。

#### P132-F：最终多种子

最终配置补 seed 2019/2020/2022/2023，加 seed2021 形成五 seed。

### 4.4 p132 指标

每个 fold 同时报告：

1. 所有 132 个提前期的平均 MAE/RMSE/bias；
2. 132 点逐提前期 MAE；
3. 每 132 月取一个起点的无重叠直接周期曲线；
4. 曲线级 MAE/RMSE/bias/R²；
5. 13 月平滑后的峰/谷幅度误差与时间误差；
6. 每折均值、标准差与最差折。

主选择指标为无重叠直接周期曲线 MAE；峰谷指标为并列目标，不能只报平均 MAE。

### 4.5 选择规则

- 结构阶段：cycle MAE 最小者进入候选集合；3% 以内保留，最差折更优者优先；
- lr/batch/dropout/heads：以同折 cycle MAE 为主，峰谷与最差折为辅；
- 最终五 seed：报告 cycle MAE、全步 MAE、峰幅度、谷幅度、峰时间、谷时间；
- 单 seed 明显胜出但四折方向不一致的配置，不得写成稳定最优；
- 测试集/外层验证不得用于改 checkpoint、epoch 或超参数。

## 五、p24 与 p132 的最终比较

两边分别冻结后，才允许比较。比较不使用各自“最好看的 MAE”直接相减，而是：

1. 对齐同一 fold、同一日期；
2. 只保留两边都有预测的日期交集；
3. 对同一真实序列计算 MAE、RMSE、bias；
4. 对 13 月平滑曲线识别峰谷，比较幅度和时间；
5. 报告 p24 递推的调用次数与 p132 的直接调用次数；
6. 若结论依赖少数 fold，标记为不稳定。

## 六、可证伪假设

### p24

- 若 P36 已稳定：五 seed Full/Block24 均值与三 seed 差不超过 3%，且 `lr=1e-3/bs32` 不显著胜出。
- 若不稳定：新 seed 或交互组合造成方向翻转，则正式冻结推迟。

### p132

- 若 p132 有希望：至少一个配置的 cycle MAE 在五折上不劣于 p24 同日期曲线，并在峰谷时间或递归稳定性上有明确优势。
- 若 p132 失败：多数配置的峰谷幅度严重压缩、时间错位或 fold 间离散度显著大于 p24，则记录负结果并停止扩展参数网格。

## 七、预尸检

| # | 失败模式 | 根因 | 防御 |
|---|---|---|---|
| 1 | p132 指标虚高 | 滑窗高度重叠，误当独立周期样本 | 主指标用无重叠 132 月曲线，滑窗全步只作诊断 |
| 2 | p132 checkpoint 抖动 | 验证窗口太少或高度相关 | 160 月内层验证（每块 29 个重叠窗口）+ 五 seed 复核 + 报告最差折 |
| 3 | 外层验证间接参与调参 | 看到 test 后改配置 | 预登记阶段矩阵；只按验证与既定规则选型 |
| 4 | p24/p132 直接横比不成立 | 任务、horizon 和样本结构不同 | 最终只比同日期曲线与同定义峰谷 |
| 5 | 训练发散的模型被临时 clip 救活 | 违反止损 | NaN/发散即记录失败，不加绕过补丁 |
| 6 | p132 输出头数值尺度或逆变换错误 | 132 步输出与 scaler 逆映射未验证 | 冒烟 + shape/日期/scaler 检查 + 物理值范围检查 |
| 7 | 参数搜索过拟合五折 | 试太多配置 | 分阶段单变量、top-2、3% 容差、多 seed |

## 八、止损

- 泄露检查失败：停止所有训练。
- p132 单折冒烟出现 shape、日期、NaN、OOM：修复根因并重做冒烟；不进入批量。
- 连续 3 个 p132 结构配置都出现峰谷崩塌或 fold 间离散度失控：停止扩展，写负结果。
- 图内指标与 `result.txt`/summary 不一致：撤图，先修评估。
- 未归类未跟踪文件：不得 commit。
