# 第 0 轮方案：训练动态与选模口径体检（D2）

> 状态：**方案，等景修批准后执行**（景修已批 D2，要求"先给我方案"）。
> 目的：判断**"最佳 val 模型"这个正式选模口径是否可靠**——若不可靠，后面所有配置比较都在噪声里做。
> 定位：诊断，不是实验；本轮**不产出任何新基线**。

---

## 一、为什么必须做这一轮（依据）

1. **最佳 val 落在很前面的轮次**：EXP-26 第 4 轮、EXP-27 第 5 轮、EXP-29 第 8 轮、EXP-28 第 16 轮。
2. **val 曲线震荡大**：EXP-26 前 8 轮 = 0.594 / 0.308 / 0.287 / **0.261** / 0.294 / 0.309 / 0.288 / 0.320（相邻轮最大跳 ±9%，峰谷差 ±20%+）。
   → "最佳 val"可能只是"哪一轮运气好"。
3. **"最佳 val 更好"并不普遍成立**：`result.txt` 每次实验两行（训练段=末轮模型 / 补测段=最佳 val 模型），
   新环境 6 组里 4 组是"最佳 val 更好"，**2 组（EXP-29 / EXP-30，都在 W3）反而是末轮模型更好**。

## 二、三层做法（成本递增；先做 L-0，够用就不往下走）

### L-0：零代码改动（约 10 分钟，可立即做）

**关键事实**：`exp_main.py` 的**训练循环每个 epoch 都算了 test loss**，日志里就是这一行：
```
Epoch: 49, Steps: 172 | Train Loss: 0.2169412 Vali Loss: 0.1590562 Test Loss: 0.1485112
```
→ **不需要改任何代码**，就能拿到 6 组（EXP-25~30）的逐 epoch 三条曲线。

**产出与判据**：

| 项 | 说明 |
|---|---|
| ① best-val 轮 vs best-test 轮 | 逐组列出；判据：**≥2 组相差 >5 轮 → 判"口径不稳"，进 L-1** |
| ② val 曲线震荡幅度 | 前 10 轮的相邻差最大值、峰谷比；判据：**>30% → 判"不稳"** |
| ③ 训练段 vs 补测段在 test 上的差 | 用 result.txt 两行（已有），判断"选最佳 val 到底赚了多少" |
| ④ val 与 test 曲线的相关 | 若弱相关 → 说明 val 段（1985-08~1996-07 / 2008-12~2019-11 等）不代表性 |

**产出物**：6 组对照表 + 一张三线图（train/val/test vs epoch）+ 一句话结论（口径要不要动）。

### L-1：小改代码（约 30 分钟，**需单独批准**）

若 L-0 判"不稳"，才需要：**训练时每 N 轮存一次 checkpoint**，这样能对每个 epoch 的模型算真正的
全步 MAE / block24（现在只能算 loss，因为只存了"最佳 val"和"末轮"两个权重）。

| 项 | 内容 |
|---|---|
| 改动文件 | `PatchTST_supervised/exp/exp_main.py`（训练循环内） |
| 改动内容 | 每 N 轮（建议 N=5）额外保存 `ckpt_epoch{N}.pth`；**不改评估路径、不改默认行为** |
| 改动量 | 约 5-8 行 |
| 风险 | 磁盘占用（每次 16 MB × 10 个 × 若干实验）；其余无 |
| 报批 | 按项目红线，改训练脚本前先出改动 diff 给景修看 |

### L-2：改选模口径（最重，单列一轮）

候选：val 用滑动平均判优 / 加长 val 段 / 多模型平均 / 干脆用"末轮模型"。
**代价**：选模口径是正式口径，一改，**全部历史数字失去直接可比性**（历史全用 best-val）。
→ 因此 L-2 必须单列一轮并显著标注，不能顺手做。
