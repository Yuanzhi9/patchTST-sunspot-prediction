# 太阳黑子预测项目汇报 — 2026-06-14

## 摘要

本项目用 **M4 Waldmeier 参数化 Gamma 曲线**做周期包络（战略层） + **PatchTST** 做残差修正（战术层），双线协同预测太阳黑子数（SSN）第 25、26 活动周完整变化曲线。历经 15 次基线实验和一系列分阶段训练尝试后，当前最优 PatchTST 模型（d_model=128, R²=0.568, 物理 MAE=23.87 SSN）面临的核心矛盾是：**MSE loss 下峰值区域（SSN>150）误差达 68.8 SSN，预测值系统性偏低。** 换 loss（Huber）不解决此问题——瓶颈不在损失函数形式，在预测目标本身的数值分布。师兄的 M4 Waldmeier 代码已验证：Cycle 24 MAE=10.89（R²=0.863），Cycle 25 MAE=6.14（R²=0.710），包络拟合能力强但仅描述趋势轮廓，缺乏精细波动。**推荐走 Level 3 残差预测路线**：将 PatchTST 的预测目标从 SSN 绝对值改为 SSN 偏离 M4 包络的残差，M4 负责低频趋势（包络），PatchTST 负责中高频偏差修正，从任务定义层面解决峰值压制。

## 一、项目目标

用 M4 Waldmeier 参数化 Gamma 曲线输出周期包络，PatchTST 在此基础上预测残差（SSN - M4_envelope），两者叠加得到完整预测曲线。最终目标：对第 25 周做完整留出验证，对第 26 周做弱/中/强三情景预测。

## 五、方法路线差异

三条路线，不是一条直线。

**路线 A：M mode + RevIN=1 + StandardScaler。** 最终收敛到 EXP-14：sl96, pl24, dm128, nh8, el2, df2048, patch16/stride8, RevIN1, StandardScaler, MSE, bs16, epochs10。RSE=0.304, R²=0.568，当前最优。
**路线 B：MS mode + RevIN=0 + 多种 scaler/activation/loss 消融。** EXP-5~11，sl132, pl24, dm512, RevIN0。RSE 底线 0.389，全面劣于路线 A。7 次实验本质是在错误基础上做局部优化。
**路线 C：1867+ 截断 + 小模型架构。** EXP-12，sl132, dm128, nh16, el3, df256, RevIN1。RSE 0.52~0.64，放弃。

## 七、从失败中提炼的核心认知

**1. 单变量对照是唯一可靠的实验方法。** MS 路线（EXP-5）一次改 3 变量，退化后无法归因，浪费整条消融路线。1867+ 路线（EXP-12）同理。直到 EXP-14（只改 dm）才得到可靠结论。

**2. Z-score 指标会骗人，物理单位评估不可省略。** EXP-2 的 RSE=0.196 比 EXP-14 的 0.304 好看，但 EXP-2 物理 MAE 远高于 EXP-14。以后所有实验必须在物理单位下按 SSN 区间做误差分层。

**3. 换 loss 不解决峰值压制。** EXP-9 Huber loss 的 RSE 和 MSE 完全一样。问题不在 loss 形式，在预测目标本身的数值分布——直接回归 SSN 时，峰值段大数值天然主导梯度。必须改任务定义。

**4. 降参有用但有天花板。** dm512→128 带来 ~5% R² 提升，但峰值误差仍 68.8。瓶颈不在模型容量，在任务定义。

**5. 数据切分决定可比性。** 全量 1749 vs 1867+ vs pre-1996 的结果不可直接比 RSE。

**6. MS mode + RevIN=0 的退化不是单一变量的锅。** 7 次消融逐一排除了 ES/Scaler/激活/Loss，无一能单独解释退化。最可能原因：MS 模式对 PatchTST 的通道独立设计有结构性不匹配，加上 RevIN=0 丢了归一化增益。

## 八、分阶段训练（已暂停）

三种阶段检测方法（A v1 自适应百分比 / B 固定等分 / A v2 精修版），方法 A v2 标注偏差在 3 月内可用。

| 方法 | 原理 | 阶段长度 std | SILSO 偏差 |
|------|------|-------------|-----------|
| A v1 | 自适应百分比 + grid search | 6.9 | 极小值 3 月内 |
| B | 固定等分 + 峰值锚定 | ~0.3 | 牺牲物理意义 |
| A v2 | 精修版，双峰检测 | 7.0 | 极小值 ±2.5, 峰值 ±3.8 |

**四阶段独立训练结果（d_model=512, ~200 样本/阶段）：**

| 阶段 | MAE | RMSE | 相对误差 | 训练样本 |
|------|-----|------|---------|---------|
| rise | 40.4 | 48.2 | 51% | 115 |
| peak | 51.8 | 61.3 | 30% | 220 |
| decline | 36.7 | 43.9 | 49% | 279 |
| trough | 6.3 | 7.8 | 47% | 206 |

四模型阶段路由滚动预测：MAE=64.7, RMSE=77.5（峰值低估 175 vs 284）。

**六大问题清单：**

| # | 问题 | 影响 | 状态 |
|---|------|------|------|
| 1 | d_model=512 对 ~200 样本过拟合 | train loss 远低于 val loss | 已确认降参路线 |
| 2 | 验证集太小（rise val 仅 13 样本） | ES 不可靠 | 已确认关 ES |
| 3 | train/val 有 24 行重叠（seq_len 窗口跨边界） | 数据泄漏 | 待修 |
| 4 | 四阶段各自 fit StandardScaler | 跨阶段 Scaler 不一致 | 待修：统一 Scaler |
| 5 | MSE loss 压制峰值 | 峰值预测系统性偏低 | 待修：改残差预测 |
| 6 | 阶段路由不准 | 过度依赖 rise 模型 | 待修或放弃路由方案 |

**判断：** 分阶段训练的根本矛盾不是阶段划分精度，而是小样本过拟合 + Scaler 不一致 + 路由不稳定。在当前数据规模下，"分阶段 + 路由"不如直接用 M4 包络做战略分解。

## 九、M4 Waldmeier 参数化曲线（师兄代码）

### 四种方法递进

| 方法 | 名称 | 原理 | 需要观测 |
|------|------|------|---------|
| M1 | Predecessor-Successor Analog | 用 target_cycle-1 与历史 predecessor 相似度，加权历史 successor 曲线 | 0 月 |
| M2 | Early-Shape Analog | 利用目标周期前 36/48/60 月观测匹配历史曲线 | 36-60 月 |
| M3 | Waldmeier-Calibrated Analog | M2 + RidgeCV 学习早期特征→峰值/峰时/长度 | 36-60 月 |
| M4 | Parametric Waldmeier (Gamma) Curve | 偏态 Gamma 曲线参数化拟合早期观测 + Waldmeier 先验 | 36-60 月 |

### M4 核心方程

```
y(t) = floor + A * (t / tp)^alpha * exp(alpha * (1 - t/tp))
```

| 参数 | 含义 | 约束范围 |
|------|------|---------|
| A | 峰值振幅 (SSN) | [20, 350] |
| tp | 峰值时间（月） | [24, 95] |
| alpha | 偏态系数（上升/下降不对称性） | [0.8, 8.0] |
| floor | 基线 | [0, 25] |

拟合流程：Waldmeier 先验（历史周期 RidgeCV → A_prior, tp_prior）→ least_squares 优化（数据残差 + 先验残差 + 尾部归零）→ 观测段真实值衔接 → ±18% 幅度 + ±8 月峰值时间的不确定度估计。

## 十、M4 + PatchTST 融合方案阶梯

| Level | 方案 | 改动量 | 预期效果 | 根本局限 |
|-------|------|--------|---------|---------|
| **1** | 添加 cycle_phase 作为输入特征 | 最小（+2 列） | 给模型周期位置信息，可能改善趋势 | 不改变预测目标（仍是 SSN 绝对值），峰值压制依旧 |
| **2** | 添加 M4 包络值作为输入特征 | 中等（需跑 M4，+1 列） | 提供物理基线参考 | 模型仍可能保守预测，M4 包络本身有误差 |
| **3** | **残差预测（SSN - M4_envelope）** ✅ | 较大（生成包络、改数据集、改训练目标） | **根本上解决峰值压制**，残差分布更接近零均值 | 依赖 M4 包络质量；周期交界处可能不准 |
| **4** | M4 全部参数（A, tp, alpha, floor）作为特征 | 大（需全周期拟合 + 增列） | 信息量最大 | 过拟合风险高 |

### 推荐：Level 3

**依据 EXP-9 的核心发现：换 loss（MSE→Huber）不改变 RSE，瓶颈不在 loss 形式，在预测目标的数值分布。** 把任务从"回归 SSN 绝对值（0~300）"改为"回归偏离物理包络的偏差（理想情况零均值小振幅）"，MSE loss 下峰值区梯度主导自然缓解。

原理：M4 Gamma 曲线负责低频周期趋势（包络），PatchTST 负责中高频偏差修正。这本质是误差分解——把原始 SSN 拆成"物理可解释的趋势"和"数据驱动修正的偏差"两个独立子任务。

### 实施步骤

```
Step 1: 生成全历史 M4 包络
  对 Cycle 12~24 每个完整周期分别拟合 Gamma 曲线
  拼接为 1749~2025 逐月 M4 包络值 → m4_envelope.csv
  (注意周期交界处的包络衔接)

Step 2: 构建残差数据集
  residual = SSN_smooth (13-mo avg) - M4_envelope
  与 sunspot_with_cycle.csv 合并，ssn 列替换为 residual
  → sunspot_with_residual.csv

Step 3: 调整 PatchTST 训练
  模型架构和参数不变（d_model=128, sl96, pl24, 同 EXP-14）
  训练目标从 ssn 切换为 residual
  Residual Scaler 单独 fit 和保存

Step 4: 训练 + 验证
  留出 Cycle 24/25 测试，对比三组：
    a) M4 alone — 纯包络
    b) PatchTST residual alone — 纯残差预测
    c) M4 + PatchTST — 包络 + 残差叠加 (= SSN_pred)

Step 5: Cycle 26 三情景预测
  M4 出弱/中/强三条包络 → PatchTST 叠加残差
  → Cycle 26 三情景完整曲线 + 不确定度

预测还原: SSN_pred = M4_envelope + residual_pred
```

### 技术要点

- 使用 13 月滑动平均 SSN 做包络拟合，关注周期趋势而非高频波动（方案 A）
- Residual Scaler 单独 fit（残差有正有负，均值和方差不同于 SSN），推理时反归一化后再叠加 M4 包络
- 验证集无重叠，避免 seq_len=96 窗口跨边界导致的数据泄漏
- 评估维度：物理 MAE/RMSE + 按 SSN 区间分层 + 峰值区域专项评估
- 不确定度传播：M4 包络 ±18% + PatchTST 残差预测不确定度，叠加输出

### 风险

| 风险 | 缓解 |
|------|------|
| M4 包络在周期交界处样本少 | 人工检查 trough 附近包络曲线合理性 |
| 残差自相关结构可能与原始 SSN 不同 | 训练前分析残差的 ACF/PACF |
| Cycle 25 尚未结束，M4 后半段验证有限 | 用 Cycle 24 做完整留出验证补充 |
| Cycle 26 无任何观测 | 三情景覆盖 114~215，不做点估计 |
